# 第八篇　开发与维护：管理命令、构建和性能

从本篇进入中部：第八篇准备构建产物并诊断性能，第九篇完成原生与容器部署、运行维护、持续交付和故障恢复。第 81 章再用一项独立需求检验从开发到交付的完整过程。

第七篇交接一笔头像事故时，接班人拿着尝试 ID 去查引用、对象和处置结果。账号资格也常有交接，只是此前我们靠维护者在 SQL 编辑器里改一行。旧的操作回执丢了，今天重跑会不会覆盖别人刚做的恢复？这一篇从这条命令开始，把服务交给另一位开发者从头构建、执行和排障。

起点是第 62 章沿用的第 61 章配套，保留原账号、会话、记录与存储配置。第 63 章先在独立库做一次可查询的 Web 资格变更。接下来要检验换一份安装目录后 API、Worker 和 CLI 能否运行，再在实际变慢的路径上区分计算、查询和等待。这些工作针对现有的单包服务，第九篇接手部署、运行维护与升级，并在故障条件下恢复和接班。

支线 65B 从长事务深入旧版本与空间回收；第 66 章从缺少首版修订的历史记录进入数据隔离与修复。第 67 章综合核对管理命令、故障诊断和构建产物，并判断空间回收与坏记录的处置范围，再把程序和维护记录交给第九篇的制品晋级与部署。性能实验从第 64 章的构建开始，交接练习使用第 65 章的配套代码。
