# 第七篇　用户资料与文件：数据库之外的数据

第 48 章末尾有两次头像替换。后开始的一次先成功，旧请求稍后才交出文件。要决定用户此时能看到哪张图，先要知道谁在改哪份资料，其他账号又获准看到哪些字段。我们从一个能直接在 PostgreSQL 里提交的字段开始：昵称。

代码接第 47 章，第 48 章的回顾沿用该版本。保留已有密码账号、会话、素材和收件箱，在独立验证库副本上升级。第 49 章用两个已开通的账号，从本人和另一位登录者的请求核对同一张资料卡。窗口快满时，再让两个请求同时改名，观察数据库怎样决定最后一次机会属于谁。

头像把事情带到数据库之外。第 50 章先做一次临时预览：上传者得到重编码后的图片，从超限、半途断开到服务退出，都要能解释谁负责释放资源。第 51 章先以本机私有桶验证一份对象的存取权限，再接回账号。如果用户刚刚关闭展示，签出后仍然有效的链接会让这次变更迟多久生效？对象写完后即使发布引用失败，仍能按这次尝试找到候选图片。第 52 章从报障开始，读者先决定取哪些证据、能清哪些对象，再去复现。整账号删除和恢复期间的写入竞争留在第十四篇。
