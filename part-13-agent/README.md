# 第十三篇 共享契约与 Agent 接入：MCP、授权与工具

**阅读路径**：客户端与 Agent 接入专题；共享契约按客户端协作需要阅读，MCP 与 Agent 按接入目标阅读。

**起点**：已有可部署的业务、账号和 HTTPS 入口；记录工具沿用已有记录接口，接入练习工具前需先完成练习篇。

**本篇结果**：提取跨端共享契约，让 MCP 与 Agent 复用已有业务规则；在已有用户登录之上，建立面向工具客户端的授权、确认和恢复机制。

**阶段边界**：用户登录方式在第五篇说明，本篇聚焦共享契约与工具客户端授权。MCP 授权前先读第 45.1～45.3 节协议基础，无需完成外部平台登录；接入真实宿主时，沿用已有的 HTTPS 环境，并在该宿主中核对授权和工具调用。

## 章节安排
- 第 102 章 共享契约与四仓协作
- 第 103 章 MCP 服务端的职责
- 第 104 章 作为 OAuth 服务端签发授权码和访问令牌
- 第 105 章 刷新、撤销与授权恢复
- 第 106 章 设计可恢复的批量工具
- 第 107 章 把用户确认落实为服务端事实
- 第 108 章 由 Agent 生成候选表达，交给后端校验与保存
- 第 109 章 第十三篇回顾：换一个调用入口，业务边界是否仍然成立

**阅读前提**：先完成所选接入路线：共享契约阅读第 102 章；MCP 与 Agent 路线继续完成第 103～108 章，并满足所调用业务的前置条件。
