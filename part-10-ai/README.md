# 第十篇 接入 AI：外部调用、费用与结果质量

下部从上部已部署的 EPP 继续，中文意图仍可空；第 78 章的必填演练、第 80 章启用插入保护的受邀实例与第 82 章的预约服务各自使用独立环境。从这里开始，候选表达有了新的来源：模型可能在用户修改原文之后才返回结果。第十篇先解决这一次调用怎样计费、校验和写回，再把已有的表达、账号与任务用于后面的专题。

**阅读路径**：EPP 专题。

**起点**：记录、采纳、后台任务与基本运维已完成；现在需要让候选内容由模型生成。

**本篇结果**：以真实模型替换示例候选来源，扩展持久化调用、费用记录和质量判断，继续复用原有确认与采纳流程。

**阶段边界**：先沿记录生成一条业务链讲透。首次真实调用同时建立供应商适配与业务边界；结果校验、持久化任务、费用控制和质量评价各自接续。练习调用随练习业务实现。模型访问条件不足时保留现有示例输入，不重复建设 Fake 层。

## 章节安排
- 第 83 章 在业务边界内完成一次真实的模型调用
- 第 84 章 让生成结果符合业务契约
- 第 85 章 将 AI 调用编排为持久化任务
- 第 86 章 配置 用量与费用控制
- 第 87 章 评价 AI 功能 而不只看几个演示
- 第 88 章 第十篇回顾：模型返回成功之后，业务是否完成

**阅读前提**：先完成第 83～87 章。
