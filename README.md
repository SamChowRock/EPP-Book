# EPP 后端开发实践

面向已有 JavaScript、前端开发和前后端联调经验的开发者，从空项目开始，逐步搭建一个公开的 EPP，掌握后端开发与维护。\
围绕 Node.js、Nest、数据库与部署运维，在同一个持续演进的项目中讲清原理、实现与取舍；所需代码随实践逐步编写。\
全书分为三部。[上部 开发一个后端服务](#上部-开发一个后端服务)（第一至七篇，第 1～62 章）建立接口、数据、身份、后台任务与文件能力。[中部 交付与运维一个后端服务](#中部-交付与运维一个后端服务)（第八至十篇及独立交付，第 63～82 章）完成构建、性能诊断、原生与容器部署，再处理运行、发布和恢复。[下部 在已有服务上演进产品能力](#下部-在已有服务上演进产品能力)（第十一至十五篇，第 83～114 章）沿用同一套服务，继续处理模型调用、搜索、练习、Agent 工具与账号处置。

学习默认使用开启本机调试与自动重启的开发模式，通过 Postman 等图形客户端发送和保存请求，修改保存后再次点击发送验证；生产构建与运行方式在对应章节分别声明。首次跟做前可按[开发环境配置（macOS）](environment-setup.md)准备所需软件。

每篇以导读明确起点，在末章或独立综合实践中回顾能力并衔接后续内容。综合实践在完成本篇相应主线后进行；可选路线只核对已选择的部分，不能成为核心路线的新前提。中部在第 82 章从已有服务的恢复转入新需求的独立交付；下部在第 114 章用所选专题完成综合实践。

[目标与能力路线](backend-capabilities.md)说明各项后端能力由哪些章节共同建立，以及怎样通过改变约束、跨场景应用和独立交付核对。EPP 的功能进度与读者能力进度分别维护；必要基础的覆盖范围由独立后端开发的目标决定。
